# Assets and implementation sources

The visual reference remains the [user-supplied course application](https://github.com/luiscoco/Udemy-Claude-Agent-SDK-lesson01-app). Its large typography, blue/orange accents, teaching sections and astronaut are carried into this Vue/Python adaptation.

`frontend/public/astronaut.png` is reused unchanged from the local course editions. Original course source: [astronaut.png at commit 832439954c11d4f3623d1b4a311f7dd67389fcc8](https://github.com/luiscoco/Udemy-Claude-Agent-SDK-lesson01-app/blob/832439954c11d4f3623d1b4a311f7dd67389fcc8/public/astronaut.png). It is included for this requested adaptation with descriptive alt text.

The existing local CSS and UML geometry informed the design. This edition's templates use Vue, FastAPI and the Python SDK. PlantUML aliases are valid independent identifiers. All 16 code explanations are extracted from this new project's source. No entire project directories, real environment files or credentials were copied.

Official implementation references:

- [Vue quick start](https://vuejs.org/guide/quick-start.html)
- [Vue Router](https://router.vuejs.org/)
- [FastAPI tutorial](https://fastapi.tiangolo.com/tutorial/)
- [Python Claude Agent SDK reference](https://code.claude.com/docs/en/agent-sdk/python)

Versions were resolved from npm and pip, pinned, installed and verified locally. The runtime uses local diagrams and syntax grammars rather than hosted diagram generation or CDN scripts.
